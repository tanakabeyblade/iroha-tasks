iroha-tasks: Privacy policy

iroha-tasks is a personal tool used only by its owner.

What it accesses

With the owner's permission, it uses the Google Tasks API to read, create and update task lists and tasks in the owner's own Google account. It requests no other Google data.

How the data is used and stored

Task data is used only to show and manage the owner's to-do list. The sign-in token is stored only on the owner's own home server.

Sharing

Google user data is not sold, not shared with anyone, and not used for advertising.

Removing access

The owner can remove access at any time in their Google Account settings, under third-party connections.
